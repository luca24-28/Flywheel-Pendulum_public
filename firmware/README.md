Pico SDK .c and .h files for pendulum swing up and catch. Pendulum.c is the main file, encoder.c is for the pendulum magnetic encoder, and fwendcoder.c is the flywheel quaderature encoder. phbridge.c is where the motor driver initialization and control + swing up interrupt lives. pglobals.h is where all global variables shared by function live. The pio file comes from Raspberry Pi example code and is copyrighted as such.
