# Reaction-Wheel Inverted Pendulum

**Embedded LQG Control | State Estimation | Mechatronics | Real-Time Systems**

An independently designed and built reaction-wheel inverted pendulum featuring a discrete Linear Quadratic Gaussian (LQG) controller, custom motor-drive electronics, and real-time state estimation implemented on a Raspberry Pi Pico.

The system uses a motor-driven reaction wheel to swing the pendulum toward its upright equilibrium and maintain balance through closed-loop feedback.

Experimental validation across nine trials:

| Performance Metric | Result |
|---|---|
| Successful catches | 9/9 |
| Mean steady-state angular RMSE | 0.227° |
| Mean angular estimation RMSE | 0.072° |
| Mean reduction in flywheel-speed variation | 43.8% |
| Control loop period | 2 ms |

All nine trials demonstrated successful catches and sustained balancing without an observed fall. Steady-state RMSE was evaluated over a three-second interval for each trial.

## System Overview

The pendulum is stabilized using reaction torque generated by accelerating a flywheel. Motor actuation is controlled by a custom H-bridge, while angular position, flywheel speed, and motor current measurements provide feedback for the state estimator.

### Hardware
- Raspberry Pi Pico microcontroller
- Geared DC motor with quadrature encoder
- Custom H-bridge motor driver with current sensing
- Pendulum angle encoder
- Custom CAD-designed and 3D-printed mechanical assembly

### Software and Tools
- **C / Pico SDK:** Embedded control, sensor acquisition, PWM generation, and real-time execution
- **MATLAB:** State-space modeling, LQR design, and Kalman filter tuning
- **Python:** Serial data logging, visualization, and experimental performance analysis

## Control System

The controller uses a four-state electromechanical model:

**x = [θ, θ̇, ρ, i]ᵀ**

Where:
- θ: Pendulum angle
- θ̇: Pendulum angular velocity
- ρ: Flywheel angular velocity
- i: Motor current

The continuous-time dynamics were linearized around the upright equilibrium and discretized for implementation at a 2 ms sampling period.

### State-Feedback Control

A discrete Linear Quadratic Regulator (LQR) computes the motor command based on the estimated state:

**uₖ = −K(x̂ₖ − x_ref)**

The feedback gain was designed in MATLAB and subsequently tuned through experimental testing to account for actuator limitations, mechanical friction, and other nonidealities.

### State Estimation

A discrete Kalman filter estimates the system state using sensor measurements and the state-space model.

The observer combines pendulum angle, flywheel speed, and motor current measurements to estimate states that cannot be directly or reliably measured.

## Engineering Challenges and Iteration

Several challenges required changes to both the mechanical system and controller implementation.

**1. Large oscillations near upright**

Early controller configurations produced large limit-cycle oscillations. Analysis of the controller response and actuator behavior indicated excessive penalties on control effort, compounded by friction and motor dead-zone effects.

The LQR weighting matrices were retuned to improve control authority near the upright equilibrium.

**2. Pendulum angle calibration**

The encoder's initial zero position did not correspond exactly to the physical upright equilibrium.

Repeated static measurements were used to determine an angular offset, which was incorporated into the feedback system.

**3. Flywheel-speed measurement noise**

The quadrature encoder produced noisy, quantized velocity measurements.

A model-based Kalman estimator was tuned to reduce measurement variation while retaining useful dynamic information for feedback.
